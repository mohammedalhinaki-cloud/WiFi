# مِرْصاد — تدقيق أمان Wi‑Fi

واجهة عربية سريعة ومتجاوبة لجرد شبكات Wi‑Fi التي تملكها، مراجعة بروتوكول الحماية، وتحليل قوة عبارة مرجعية محليًا. ينفذ المختبر محاكاة دقيقة ومحدودة تصل إلى 50 ألف تخمين ملموس داخل ذاكرة المتصفح، لكنه لا يلتقط مصافحات، ولا يستخرج كلمات مرور محفوظة، ولا يرسل أي محاولة اتصال أو تسجيل دخول إلى الشبكة.

## لماذا هذه البنية؟

المشروع مقسوم إلى طبقتين صغيرتين:

1. **واجهة ثابتة (React + TypeScript + Vite)**
   - تعمل بالكامل داخل المتصفح ويمكن نشرها على GitHub Pages.
   - خوارزمية التحليل الأساسية موجودة في `src/lib/password.ts` داخل `analyzePassword`؛ تستخدم `zxcvbn` محليًا ثم تضيف فحوص Wi‑Fi قابلة للتفسير للطول، تنوع الأحرف، الكلمات الشائعة، SSID والكلمات المرتبطة التي يدخلها المستخدم، التسلسلات، التكرار والأنماط المتوقعة.
   - تشغّل `simulateTargetedGuessing` قائمة محدودة ومرتبة من التخمينات الفعلية (شائعة، سياقية، بدائل أحرف، سنوات، دمج كلمات، وأنماط رقمية) وتقارنها بالعبارة المرجعية في الذاكرة فقط. تعرض رتبة المطابقة، الاستراتيجية، الزمن، والمعدل المقاس، وتتوقف بحد أقصى ثابت لتبقى الواجهة سريعة.
   - تعرض النتيجة أيضًا عدد الاحتمالات النظري، التخمينات الفعالة، الإنتروبي، مقاومة التخمين، ومستوى ضعيفة/متوسطة/قوية/قوية جدًا، مع نموذج زمني واضح `التخمينات المتوقعة ÷ 2 ÷ معدل المحاولات`.
   - لا تُخزّن كلمة المرور. يُحفظ فقط ملخص النتيجة في `localStorage`.
   - توليد الكلمات يستخدم `crypto.getRandomValues` مع رفض الانحياز الإحصائي، وليس `Math.random` أو قائمة ثابتة.
2. **مساعد مسح محلي اختياري (Node.js)**
   - يستدعي أدوات النظام للقراءة فقط: `nmcli` على Linux، و`airport` حيث يتوفر على macOS، و`netsh` على Windows.
   - يعرض SSID، قوة الإشارة، القناة، ونوع الحماية؛ ولا يحاول الاتصال بالشبكة.
   - عنوان BSSID يُحجب قبل إضافته إلى الواجهة.

اختيرت هذه البنية لأن متصفحات الويب — لسبب أمني — لا تسمح لموقع ثابت بفحص محولات Wi‑Fi. لذلك يعمل المسح التلقائي عبر Backend/مساعد محلي مصرح به، ويمكن الآن ربط مساعد المسح المحلي حتى من نسخة GitHub Pages، بينما تبقى الإضافة اليدوية واستيراد JSON والتحليل متاحة دائمًا.

## المزايا

- دعم عدة شبكات مع نتيجة مستقلة لكل شبكة.
- تقييم مركب من 100 للبروتوكول وقوة العبارة السرية.
- كشف الكلمات الشائعة، اسم الشبكة، التسلسلات، التكرار، وضعف الطول.
- محاكاة 50 ألف تخمين محلي ملموس مع عرض المطابقة الدقيقة ورتبتها وسرعة التنفيذ الفعلية.
- تقدير عدد الاحتمالات والإنتروبي ووقت التخمين في سيناريو محلي افتراضي وسيناريو اتصال محدود.
- مراعاة اختلاف معدل التقدير بين WPA2 وWPA3 مع تنبيه واضح أن الزمن تقريبي.
- مولّد كلمات مرور قوي محليًا مع نسخ آمن.
- تقرير منقّح للطباعة أو التصدير بصيغة JSON (دون كلمات مرور أو BSSID كامل).
- تصميم RTL متجاوب، تنقل سفلي للهاتف، ودعم تقليل الحركة.
- بيانات تجريبية واضحة لعرض الواجهة لأول مرة.

## التشغيل المحلي

### المتطلبات

- Node.js 20 أو أحدث (مُختبر على Node.js 22).
- مدير الحزم npm.
- للمسح التلقائي على Linux: `NetworkManager` وأمر `nmcli`.

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يعرضه Vite. خادم التطوير يستمع إلى `0.0.0.0` ويمرر `/api/scan` إلى مساعد المسح المحلي. هذا المسار يعيد JSON دائمًا، ويُرجع خطأ JSON واضحًا عند غياب أداة النظام بدل صفحة HTML.

إذا أردت استخدام نسخة GitHub Pages نفسها مع جهازك، شغّل مساعد المسح في طرفية ثانية:

```bash
npm run scan:server
```

سيستمع المساعد افتراضيًا على `http://127.0.0.1:8787/api/scan`، ثم افتح **فحص شبكة جديدة → مسح محلي → تغيير عنوان Backend المسح** والصق العنوان الافتراضي واضغط **حفظ وتجربة**. يُحفظ العنوان في هذا المتصفح فقط. يبقى المساعد مربوطًا بـ loopback ولا يعرّض محول Wi‑Fi للشبكة المحلية. غيّر `WIFI_SCAN_PORT` عند الحاجة. إذا كان Backend بعيدًا، اضبط `WIFI_SCAN_ORIGINS` على أصل الواجهة بدل فتح CORS عشوائيًا.

لربط واجهة منشورة بخادم مسح مستقل، يمكن أيضًا ضبط متغير البناء قبل `npm run build`:

```bash
VITE_WIFI_SCAN_API=https://scanner.example.test/api/scan npm run build
```

يجب أن يكون الخادم مستقلًا، مصرحًا به، ويدعم `GET` ويعيد `Content-Type: application/json` وبنية `{ "networks": [...] }` مع إعداد CORS مناسب. من دون هذا المتغير أو ربط عنوان من داخل الواجهة، يكتشف التطبيق نطاق GitHub Pages ويتوقف عن طلب `/api/scan` حتى لا يحاول تحليل صفحة 404 أو `index.html` كأنها JSON.

### مسح من سطر الأوامر

```bash
npm run scan
```

يمكن حفظ الناتج ثم استيراده من تبويب **استيراد**:

```bash
npm run scan > my-networks.json
```

مثال بنية ملف متوافق:

```json
{
  "networks": [
    {
      "ssid": "Home_5G",
      "signal": 88,
      "channel": 36,
      "frequency": 5180,
      "security": "WPA3",
      "connected": true
    }
  ]
}
```

## اختبار شبكاتك

1. شغّل المشروع محليًا ثم اضغط **فحص شبكة جديدة**.
2. اختر **مسح محلي**. إن لم يدعم نظامك المسح، استخدم الإضافة اليدوية أو استيراد JSON.
3. ضع علامة الملكية فقط على الشبكات التي تملكها أو لديك تفويض صريح بشأنها.
4. افتح بطاقة الشبكة واضغط **اختبار كلمة المرور**.
5. أدخل العبارة المرجعية الحالية، ويمكنك إضافة كلمات مرتبطة بها اختياريًا مثل اسم المكان أو المالك. يشغّل المختبر حتى 50 ألف تخمين محلي ويقارن كل مرشح بالعبارة داخل الذاكرة؛ ولا يحاول التحقق منها عبر الاتصال بالراوتر.
6. راجع رتبة المطابقة الفعلية، النتيجة الإحصائية، الملاحظات، ومربعات «ما الذي يقويها؟». غيّر الكلمة من لوحة الراوتر نفسها إذا لزم الأمر، ثم أعد الاختبار.

> **مهم:** نتيجة «التخمين المحلي الفعلي» دقيقة داخل القائمة المحدودة: المطابقة تعني أن مرشحًا ملموسًا ساوى العبارة المرجعية. أما عدم المطابقة فلا يثبت أن العبارة غير قابلة للكسر بقوائم أو موارد أكبر. «وقت الكسر» الأطول نموذج تقديري للمقارنة وليس ضمانًا؛ يختلف بحسب البروتوكول، العتاد، إعدادات KDF، وجود PMF، تحديد المحاولات، وطراز الراوتر. في WPA3/SAE لا ينطبق نموذج التخمين غير المتصل بنفس طريقة WPA2، لذلك يستخدم مرصاد معدلًا محافظًا جدًا ويعرض هذا بوضوح. لا تتصل المحاكاة بالراوتر، ولا تستقبل handshake أو مادة تحقق؛ لذلك لا تستطيع التحقق من كلمة مجهولة على شبكة حقيقية.

## الأوامر

```bash
npm run dev         # تشغيل محلي مع واجهة API للمسح
npm run build       # فحص TypeScript وبناء النسخة الثابتة
npm run preview     # معاينة dist مع دعم المسح المحلي
npm run scan:server  # تشغيل Backend محلي مستقل للنسخة المنشورة
npm test            # اختبارات التحليل والتطبيع
npm run lint        # ESLint
npm run scan        # إخراج جرد Wi-Fi محلي كـ JSON
```

## النشر على GitHub Pages

يوجد سير عمل جاهز في `.github/workflows/deploy-pages.yml`:

1. من إعدادات المستودع افتح **Settings → Pages**.
2. اختر **GitHub Actions** كمصدر النشر.
3. ادفع إلى الفرع الرئيسي أو شغّل سير العمل يدويًا.

النسخة المنشورة ثابتة، ولا تستطيع وحدها قراءة محول Wi‑Fi بسبب قيود المتصفح. أصبح بالإمكان ربطها بمساعد المسح المحلي عبر **تغيير عنوان Backend المسح** كما هو موضح أعلاه؛ أو استخدام Backend مستقل مصرح به. من دون أحد هذين الخيارين تبقى الإضافة اليدوية، الاستيراد، التحليل، التوليد والتقارير متاحة دون خادم.

## حدود الأمان والنطاق

مرصاد أداة **دفاعية** ولا ينفذ:

- التقاط handshake أو PMKID.
- حقن حزم، deauthentication، أو تجاوز مصادقة.
- إرسال التخمينات إلى الراوتر أو تنفيذ محاولات مصادقة عليه؛ التخمين الفعلي المتاح محاكاة محلية محدودة ضد العبارة المرجعية فقط.
- استخراج كلمات مرور من الجهاز/الراوتر أو التحقق من كلمة مجهولة بلا مادة تحقق مصرح بها.
- إرسال كلمة المرور أو تقريرها إلى خدمة خارجية.

استخدمه فقط مع شبكات تملكها أو لديك إذن صريح لتدقيقها.
